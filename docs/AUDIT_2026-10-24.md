# Audit — code_attach (responsibility boundaries, refactoring, bugs)

Scope: `code_attach/`, the `coding_agent/` primitives it uses, `examples/local_app.py`, `coding_agent/activity_log.py`. Method: full read plus executed probes for every item marked VERIFIED. Items marked FIXED have a regression test in `tests/test_code_attach_audit.py` (or the privacy tests).

## A. Bugs

| # | Sev | Finding | Status |
| --- | --- | --- | --- |
| A1 | High | **Task cap was lifetime, not concurrent.** `len(self._tasks) >= max_tasks` counted finished tasks, so after 64 tasks ever started the backend answered 429 until restart. VERIFIED (cap 3 -> Busy at the 4th finished task). | FIXED: cap counts active tasks; finished tasks kept up to `keep_finished` (256), oldest evicted with their idempotency keys |
| A2 | High | **Host secrets reached approved test commands.** Child processes inherited the full environment; a model-authored test could print `OPENAI_API_KEY` etc. and the output goes to the model provider and the browser. | A3 | High | **Privacy fix was incomplete.** `scrub()` missed the doubled-backslash spelling that `str(OSError)` produces; only the user name was masked by accident, `C:\\Users\\...\\AppData\\...` structure leaked. ## B. Responsibility boundaries

| # | Finding | Status |
| --- | --- | --- |
| B1 | Host layer (router/providers) has no execution, no `coding_agent`, no network (AST-enforced). Agent layer has no HTTP/model client; only `tools.py` runs processes. Holds. | OK |
| B2 | `tools.py` reaches into `Workspace._resolve` (private) from six places and re-implements directory walking and per-file safety checks. Path policy is split between `coding_agent` and `tools`. | OPEN refactor: expose `Workspace.resolve()` and `Workspace.iter_files()` publicly; `_resolve` per file is also slow at 20,000 files |
| B3 | Host wiring is told to import `ActivityLog` from `coding_agent.activity_log`, i.e. the host depends on the primitives package, contradicting "host writes adapter only". | OPEN: re-export from an agent-layer module and update the boundary test |
| B4 | `examples/local_app.py` returns the **absolute log directory** (contains the OS user name) from `/api/config` to the browser and prints it. Contradicts the no-personal-path rule. | OPEN (owned by the session that wrote it; show a relative/`~` form) |
| B5 | `kpi/real_eval.py` imports the fixture builder from `tests/`. Dev tooling depending on test code. | OPEN, low |
| B6 | Privacy policy (`scrub`) lives in `ToolBox` but is applied by `Task`; acceptable, but the activity sink receives only already-scrubbed tool output, while `instruction` and read file contents are logged verbatim. | NOTE |

## C. Refactoring and design notes

1. `t_apply_proposal` pops the proposal before applying; a transient `PermissionError` (editor lock on Windows) forces a re-proposal. Consider restoring the proposal on `OSError`.
2. `Task` mixes loop, approval state machine and logging fallbacks (three duplicated "append event despite log failure" blocks). Extract an `_emit_safe`.
3. Encoding: introduce `read_text(path) -> (text, encoding)` and `write_text(path, text, encoding)` in `coding_agent`, used by edit/propose/search, to fix A7 without touching callers.
4. Messages grow without bound (up to ~32 KB per tool result x steps); no context-window management. A long task can exceed the model's limit and fail as `FAILED`.
5. Every event is `fsync`ed while holding `Task._cv` (and `Engine._lock` on start): pollers and task starts serialize behind disk latency.

## D. Inherent exposure (not defects, but the owner must know)

- Whatever the agent reads (file contents, search hits, diffs, test output) is sent to the model provider behind the host's `complete`. The path denylist covers `.env`, keys and similar names, not secrets embedded in ordinary files (for example a password in an `.ini`).
- Approved test commands execute project code with the backend's privileges (environment now filtered, filesystem and network are not).
- Activity logs contain instructions, source excerpts and diffs; they are unredacted and unlimited in retention.
