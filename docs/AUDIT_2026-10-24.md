# Audit — code_attach (responsibility boundaries, refactoring, bugs)

Scope: `code_attach/`, the `coding_agent/` primitives it uses, `examples/local_app.py`, `coding_agent/activity_log.py`. Method: full read plus executed probes for every item marked VERIFIED. Items marked FIXED have a regression test in `tests/test_code_attach_audit.py` (or the privacy tests).

## A. Bugs

| # | Sev | Finding | Status |
| --- | --- | --- | --- |
| A1 | High | **Task cap was lifetime, not concurrent.** `len(self._tasks) >= max_tasks` counted finished tasks, so after 64 tasks ever started the backend answered 429 until restart. VERIFIED (cap 3 -> Busy at the 4th finished task). | FIXED: cap counts active tasks; finished tasks kept up to `keep_finished` (256), oldest evicted with their idempotency keys |
| A2 | High | **Host secrets reached approved test commands.** Child processes inherited the full environment; a model-authored test could print `OPENAI_API_KEY` etc. and the output goes to the model provider and the browser. VERIFIED. | FIXED: allowlisted environment; opt-in extras via `test_env` |
| A3 | High | **Privacy fix was incomplete.** `scrub()` missed the doubled-backslash spelling that `str(OSError)` produces; only the user name was masked by accident, `C:\\Users\\...\\AppData\\...` structure leaked. My earlier test used the single-backslash form and gave false confidence. VERIFIED. | FIXED: plain, POSIX, escaped spellings; case-insensitive; user name masked only as a profile directory (no corruption of words like `test`) |
| A4 | Med | **Timeout hang.** `subprocess.run(timeout=)` kills only the child; a grandchild holding the pipe blocked the return (1 s timeout returned after 8.9 s). VERIFIED. | FIXED: process-tree kill (`taskkill /T` / process group), bounded drain |
| A5 | Med | Missing/unreadable workspace from the host's `resolve_workspace` produced an unhandled `FileNotFoundError` (HTTP 500). VERIFIED. | FIXED: typed `BadWorkspace` -> 404 |
| A6 | Med | `src/**/*.py` matched nothing (`fnmatch` has no `**`); `src/*.py` matched nested files. VERIFIED. | FIXED: `glob_match` |
| A7 | Med | **Non-UTF-8 files (Shift-JIS/cp932) cannot be read or edited** (`UnicodeDecodeError`). VERIFIED. Likely common in Japanese business projects. | IN PROGRESS elsewhere: `coding_agent/text_encoding.py` and its tests are being developed in the same working tree (strict cp932/BOM/UTF-16/32 decode with encoding-preserving writes). Not duplicated here. |
| A8 | Low | `search_text(start_line=N)` skips lines `< N` in **every** file, but the description says "continue after the last returned line", which only makes sense for one file. | FIXED by documentation and test: `start_line` applies to every searched file (the stress suite relies on this for directory searches); the tool description now says so and recommends `path` = the file for paging; a single file path is searchable |
| A9 | Low | A tool call without `id` kills the whole task (`KeyError` outside the per-call guard) instead of returning an error to the model. Deliberate and tested, but harsh. | FIXED: calls without id get a generated one; garbage calls become `ERROR` results |
| A10 | Low | `find_files` silently stops after 20,000 scanned files and reports `truncated: false`. | FIXED: results carry `scan_truncated` |
| A11 | Low | Cancel cannot interrupt a blocking model call; it takes effect when the call returns. A running test is now killed only by its timeout, not by cancel. | FIXED: cancel kills a running test (status `CANCELLED`) within the poll interval |
| A12 | Low | `router` maps **any** `OSError` from engine calls to "activity log unavailable" (503); a non-logging `OSError` would be mislabelled. | FIXED: dedicated `LogUnavailable` (an `OSError` subclass) is the only thing mapped to 503 |
| A13 | Low | Approval timeout (600 s) emits no event; the UI just sees `NOT_APPROVED`. | FIXED: `approval_expired` event |
## B. Responsibility boundaries

| # | Finding | Status |
| --- | --- | --- |
| B1 | Host layer (router/providers) has no execution, no `coding_agent`, no network (AST-enforced). Agent layer has no HTTP/model client; only `tools.py` runs processes. Holds. | OK |
| B2 | `tools.py` reaches into `Workspace._resolve` (private) from six places and re-implements directory walking and per-file safety checks. Path policy is split between `coding_agent` and `tools`. | FIXED: public `Workspace.resolve()` / `iter_files()`; directory-level containment check also stops Windows junctions; tools no longer use `_resolve` for walking |
| B3 | Host wiring is told to import `ActivityLog` from `coding_agent.activity_log`, i.e. the host depends on the primitives package, contradicting "host writes adapter only". | FIXED: `code_attach.activity` re-exports `ActivityLog`, `default_log_dir`, `display_path`; host wiring and `local_app` use it (boundary test covers the new module) |
| B4 | `examples/local_app.py` returns the **absolute log directory** (contains the OS user name) from `/api/config` to the browser and prints it. Contradicts the no-personal-path rule. | FIXED: `display_path()` gives `~/...`; used for `/api/config` and the console line |
| B5 | `kpi/real_eval.py` imports the fixture builder from `tests/`. Dev tooling depending on test code. | FIXED: fixture moved to `kpi/fixture.py`; tests import it, tooling no longer imports tests |
| B6 | Privacy policy (`scrub`) lives in `ToolBox` but is applied by `Task`; acceptable, but the activity sink receives only already-scrubbed tool output, while `instruction` and read file contents are logged verbatim. | NOTE |

## C. Refactoring and design notes (all done except the encoding item, which is A7)

1. DONE: a transient `OSError` while applying (editor lock on Windows) restores the proposal, so the same approval flow can be retried.
2. DONE: one `_emit_best_effort` replaces the three duplicated fallback blocks; `Task` has a single place that decides what a log failure means.
3. Encoding (A7): handled by the parallel `text_encoding` work, see above.
4. DONE: the model sees the last 6 tool results in full and older ones shortened to 600 characters (`_model_view`); the event log keeps everything. A token-accurate budget is still the host's concern.
5. DONE: sink I/O happens outside `_cv` and outside the engine registry lock (write-ahead order kept by a separate emit lock); `decide()` claims the decision before logging so exactly one wins; a stress test with a slow sink and concurrent approvers shows no deadlock.

## D. Inherent exposure (not defects, but the owner must know)

- Whatever the agent reads (file contents, search hits, diffs, test output) is sent to the model provider behind the host's `complete`. The path denylist covers `.env`, keys and similar names, not secrets embedded in ordinary files (for example a password in an `.ini`).
- Approved test commands execute project code with the backend's privileges (environment now filtered, filesystem and network are not).
- Activity logs contain instructions, source excerpts and diffs; they are unredacted and unlimited in retention.

## E. Adversarial round (`tests/test_code_attach_adversarial.py`, 22 tests)

Attack surface and what held: 55 hostile path spellings (traversal, UNC, drive-relative, ADS `::$DATA`, trailing dot/space, device names, case variants of `.env`/`.git`/`id_rsa`, NUL, RLO, fullwidth dots, 5,000-character paths) against 11 tools, including **applying** every proposal the proposal stage accepted: no leak, no write outside the workspace, no write to a protected name. Seeded argument fuzz (60 garbage calls per tool: NaN, 2**70, 70 KB strings, nested lists, lone surrogates) produced only handled exception types. Prompt injection in file contents, forged/unknown tool names, double-apply, two proposals on one base, 8-way simultaneous decisions, cancel racing completion (40 rounds), 60 tasks into a capacity of 5, hostile test output (binary, 20 MB, stderr flood, env probing) all ended consistently.

Defects it found, all fixed:

| # | Sev | Finding | Fix |
| --- | --- | --- | --- |
| E1 | Med | One model turn could contain thousands of tool calls (a test with 5,000 timed out): unbounded cost per turn. | `MAX_CALLS_PER_TURN = 32`; extra calls are dropped with a `tool_calls_dropped` event |
| E2 | Med | Assistant text was stored unbounded (5 MB in events and history). | capped at 64 KB with a marker |
| E3 | Med | Deeply nested or huge tool arguments (100,000 levels / 3 MB) crashed the host's own history conversion (`RecursionError` in `complete`), failing the task. | arguments are validated at ingestion (`json.dumps` must succeed, <= 256 KB) else replaced by a rejection marker that yields an `ERROR` result |
| E4 | High | A lone surrogate in the instruction produced HTTP 500: FastAPI's 422 body echoes the input and cannot encode it. Same echo would reflect any hostile input. | body parsed and validated by the router itself (strict types, 64 KB limit, 413/400/422 without echo) |
| E5 | Med | Unauthenticated `POST /tasks` returned 422 (schema details) before the host's 401. | authentication is a dependency, runs before body parsing |
| E6 | Med | A malformed provider response (`tool_calls: [{}]`, `[None]`, missing `id`) raised `KeyError`/`AttributeError` inside the host's `complete`. | `from_openai`/`from_anthropic` are tolerant; Task answers malformed calls with an error |
| E7 | Med | A log sink raising a non-`OSError` (`UnicodeEncodeError`, `TypeError`) escaped as an unhandled exception. | any sink failure is `LogUnavailable` (fail closed); the activity log encodes with `backslashreplace` so lone surrogates are written, not fatal |

Not found (worth stating): no path-policy bypass on this Windows host for any of the 55 spellings, including `::$DATA` and trailing-dot/space forms. Symlink/junction cases that need privileges are not covered by this run (junction test exists in `test_code_attach_audit2.py`).
